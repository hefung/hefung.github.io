## 🧭 关于本站

HeFung 是一个简约风格的个人开源技术站点，基于 VitePress 搭建。
本站主打实用工具、资源整理、镜像加速与日常技术笔记分享，没有冗余内容，只沉淀真正能用、能省事的干货。

> 定位：把日常折腾出来的实用脚本、好用的镜像源、整理过的资源公开出来，免费分享，随缘维护。

## 📂 站点内容

| 内容分类           | 说明                                       |
| ------------------ | ------------------------------------------ |
| ⚡ GitHub 镜像加速 | 实时测速的国内可用镜像源，一键复制加速地址 |
