# 站点简介

HeFung 是一个开源个人技术站点，基于 VitePress 搭建。
本站主打**实用工具、资源整理、技术笔记、趣味项目**，以简约清爽的页面风格，沉淀日常学习与开源分享内容。

## ✨ 站点风格

- 采用简约干净的页面设计，明暗双主题随心切换
- 布局清爽克制，无冗余内容，阅读体验舒适
- 图标与排版统一规整，整体风格统一耐看

## 📖 内容定位

- 整理各类实用工具、电脑资源、网站导航
- 收录系统激活、镜像加速、壁纸工具等开源项目
- 记录日常技术随笔、实用教程、趣味小功能
- 所有内容开源公开，免费分享、随缘维护

## 📱 全端适配

- 完美适配电脑、平板、手机所有设备
- 移动端自动适配布局，导航智能折叠
- 随时随地，流畅浏览本站所有内容

## ⚙️ 站点特性

- 页面加载快速，轻量化架构，简洁高效
- 支持自动化部署，持续更新迭代内容
- 结构清晰，分类规整，方便查阅与检索

## 🧩 收录方向

本站长期整理更新以下内容：

- Windows / Office 激活实用脚本
- GitHub 加速镜像与各类代理资源
- 精美壁纸、诗文起名、前端导航工具
- 各类自用小工具、开源实践项目、技术随笔
