### ⚡ 使用说明

- 点击【复制】拿到镜像前缀，在原 GitHub 链接前面拼接该地址即可加速下载
- 仅**正常**状态镜像可复制；超时、不支持状态无法使用，按钮已锁定
- 不支持：该代理格式不兼容，无法用于 GitHub 加速；超时：当前网络无法连通
- 所有镜像均为第三方公共服务，不保证长期稳定，建议多备用几个镜像
