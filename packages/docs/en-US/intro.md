# About HeFung

HeFung is an open-source personal tech site built with VitePress.
This site is focused on **practical tools, curated resources, dev notes and fun little projects**, with a clean minimalist style for collecting learning notes and open-source sharing over time.

## ✨ Design Style

- Clean, uncluttered page design with automatic light / dark theme switching
- Restrained layout with no extra bloat, for a comfortable reading experience
- Consistent icons, typography and visual style across the whole site

## 📖 What You'll Find Here

- Curated list of useful tools, desktop resources and site navigation links
- Open-source projects including system activation scripts, mirror acceleration and wallpaper tools
- Everyday tech notes, practical tutorials and small interesting side projects
- All content is open and freely shared, maintained on a volunteer basis

## 📱 Full Device Support

- Fully optimized for desktop, tablet and mobile screens
- Responsive mobile layout with smart collapsible navigation
- Browse the site smoothly on any device, anywhere

## ⚙️ Site Features

- Fast page loads with a lightweight architecture
- Automated deployment for continuous content updates
- Clear structure and organized categories for easy browsing and search

## 🧩 Content Categories

This site is continuously updated with:

- Practical Windows / Office activation scripts
- GitHub acceleration mirrors and proxy resources
- Wallpaper collections, naming tools and frontend navigation
- Self-use small utilities, open-source practice projects and tech essays
