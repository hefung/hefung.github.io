# 关于 HeFung

HeFung 是基于 VitePress 搭建的个人开源站点，用于整理技术笔记、收录各类实用工具与资源。

## 设计理念

一份好的技术笔记，重在内容本身，阅读体验亦不可忽视。本站坚持：

- **简约素雅**：干净克制的页面风格，让内容成为核心
- **功能够用**：满足笔记、资源收录、教程展示所需能力
- **上手轻便**：配置简单，专注内容撰写
- **灵活可调**：页面布局可按需调整，适配不同类型文档

## 主要特性

### 🎨 页面风格

- 采用简约现代的设计
- 亮色、暗色主题自由切换
- 响应式布局，适配电脑、平板、手机各类设备

### 🚀 站点能力

- 内置本地全文检索
- 支持 Mermaid 流程图绘制
- 支持双语文档，方便多语言笔记维护
- 多种页面版式可供选用

### ⚡ 轻快性能

- 依托 Vite 驱动构建
- 开发预览热更新，即时查看修改效果
- 静态页面打包输出，访问轻快

### 🔧 易于拓展

- 丰富的页面配置项
- 组件化结构，方便新增自定义模块
- 可接入各类插件扩展能力

## 维护说明

HeFung 由个人维护、开源分享。以随手记录、资源整理为主，随缘更新，分享日常实践中遇到的实用工具与技术心得。

## 技术栈

- **Vue 3** — 现代化前端框架
- **VitePress** — 基于 Vite 的静态站点生成器
- **TypeScript** — 提供类型约束，方便维护代码
- **Tailwind CSS** — 原子化样式方案
